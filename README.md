# Quran App - تطبيق القرآن الكريم (نسخة سريعة وخفيفة)

تطبيق إسلامي شامل ومميز مبرمج بلغة Flutter، يحتوي على:
- قارئ مصحف ذكي مع تنزيل تلقائي أونلاين وتحفيظ الملف أوفلاين.
- مشغل صوتيات لـ 114 سورة مع إمكانية التحميل والاستماع أوفلاين وتكرار الآيات للحفظ.
- متابع تفاعلي للختمة الشريفة.

## الميزة في هذه النسخة:
حجم المشروع وخفيف جداً ولا يتجاوز بضعة كيلوبايتات لأن ملف الـ PDF يتحمل أونلاين تلقائياً عند تشغيل التطبيق لأول مرة!
